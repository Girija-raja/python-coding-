# ⚙️ Installation

Clone the repository using:

```bash
git clone https://github.com/Girija-raja/python-coding-.git
```

Move into the project folder:

```bash
cd python-coding-
```

Run Python programs:

```bash
python filename.py
```

or

```bash
python3 filename.py
```
